## 3. Hosting

The chosen host is Cloudflare Pages (`docs/hosting-decision.md`); the Apache/PHP path still works (`docs/deployment.md` part B).

- [x] Create the Pages project `classicjewels` and connect nothing (done 15 October 2026: https://classicjewels.pages.dev/, deployed by hand). Still to do: the GitHub secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`, so that `.github/workflows/deploy.yml` builds, runs `npm run audit`, prunes `.htaccess` and `api/contact.php` from `dist/` (`scripts/prune-pages-dist.mjs`) and uploads on every push to `main` and after every gold-rate snapshot. Until then deploy by hand with `npm run build && npm run audit && npm run pages:deploy`, never with a bare `wrangler pages deploy dist` (that uploaded `.htaccess` once).
- [ ] Keep the PHP feed reachable when the domain moves. `wrangler.toml` already sets `ORIGIN_FEED_URL` to `https://classicjewels.ae/gold-rates.php`, so `/gold-rates.php` on Pages proxies the live feed today (checked 16 October 2026: 200, `application/json`, `Cache-Control: public, max-age=60, s-maxage=300`) and `rate.ts` refreshes the baked rate. Before `classicjewels.ae` points at Pages, create `feed.classicjewels.ae` on the cPanel host (or any URL that serves `gold-rates.php`) and repoint `ORIGIN_FEED_URL`; otherwise the function would be asked to proxy its own host, refuses, and answers 503 "Feed not configured" while pages keep the build-time rate.
- [ ] Email for the contact form: a Resend account, its DNS records, the `RESEND_API_KEY` Pages secret, and `CONTACT_TO` / `CONTACT_FROM` in `wrangler.toml` (keep `CONTACT_TO` identical to `RECIPIENT` in `public/api/contact.php`). - [ ] Custom domain `classicjewels.ae` on the Pages project; TLS full (strict), HSTS on (the `_headers` file already sends it); `www.` and `http://` redirected to `https://classicjewels.ae/`.
